📚 Proyecto: Catálogo de Librería (Workshop)
Este es un taller práctico de freeCodeCamp donde el objetivo principal es dominar la organización de contenido complejo mediante contenedores y selectores.

🎯 Objetivos de Aprendizaje
En este proyecto estoy aplicando:

Estructura Dinámica: Uso intensivo de elementos <div> para crear componentes (tarjetas de libros).

Identificación y Estilo: Diferenciación precisa entre class (para estilos repetibles) e id (para elementos únicos).

Jerarquía de Información: Organización de metadatos de libros (título, autor, precio, descripción).

🛠️ Tecnologías
HTML5 Semántico.

CSS3 (Diseño de Layouts y Card Components).
