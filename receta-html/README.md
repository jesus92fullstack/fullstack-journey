# Ejercicio: Receta de Cocina (HTML Semántico)

Este proyecto es parte de mi camino de aprendizaje en **FreeCodeCamp**. El objetivo principal es practicar la estructura de una página web utilizando etiquetas de **HTML5 semántico**.

## 🎯 Objetivos del ejercicio
- Utilizar etiquetas como `<article>`, `<section>`, `<header>` y `<footer>`.
- Implementar listas ordenadas (`<ol>`) para los pasos y desordenadas (`<ul>`) para los ingredientes.
- Practicar la jerarquía de títulos (`<h1>`, `<h2>`, `<h3>`).

## 🛠️ Tecnologías utilizadas
- HTML5
- CSS3 (próximamente)
