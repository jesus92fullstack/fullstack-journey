# Pantalla de Vídeo con iframe (freeCodeCamp)

Este proyecto forma parte de mi aprendizaje en el desarrollo web frontend. En este ejercicio práctico, he trabajado con la incrustación de contenido multimedia externo utilizando el elemento `<iframe>` de HTML5.

## 🎯 Objetivos del Ejercicio
* Comprender el concepto de **Elementos Reemplazados** en HTML.
* Incrustar un reproductor de vídeo de YouTube de forma accesible y segura.
* Dominar los atributos clave de control y permisos del elemento `<iframe>`.

## 🛠️ Tecnologías y Conceptos Utilizados
* **HTML5 (`<iframe>`):** Para renderizar una ventana externa dentro del documento.
* **Atributos de Seguridad y Accesibilidad:**
  * `title`: Para describir el contenido a lectores de pantalla.
  * `allowfullscreen`: Para permitir la visualización a pantalla completa.
  * `referrerpolicy="strict-origin-when-cross-origin"`: Para proteger la privacidad del usuario al comunicarse con servidores externos.

## 🚀 Cómo visualizar el proyecto
1. Clona el repositorio o descarga la carpeta `7-iframe-video-html`.
2. Para evitar el **Error 153** de restricción de reproducción de YouTube en local (protocolo `file://`), se recomienda abrir el archivo `index.html` utilizando un servidor local como la extensión **Live Server** en VS Code.
