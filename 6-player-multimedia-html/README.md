# 🎬 HTML Audio and Video Lab

¡Hola! 👋 Este proyecto es un laboratorio práctico de **freeCodeCamp** diseñado para consolidar el uso de etiquetas multimedia nativas en HTML5. El objetivo principal ha sido maquetar un reproductor que combine tanto vídeo como audio de forma accesible y semántica.

---

## 🛠️ Tecnologías y Prácticas Aplicadas

* **HTML5 Semántico:** Uso de etiquetas `<section>` para separar lógicamente los bloques de contenido.
* **Multimedia Nativa:** Implementación de las etiquetas `<video>` y `<audio>`.
* **Rutas Robustas:** Uso de la etiqueta `<source>` dentro del reproductor para permitir múltiples formatos y asegurar la compatibilidad entre navegadores.
* **Atributos de Control:** Uso de `controls`, `loop` y `width` para mejorar la experiencia de usuario.

---

## 📂 Estructura del Proyecto

* `index.html`: Archivo principal con la estructura del laboratorio y los reproductores multimedia.
* `README.md`: Documentación del proyecto (este archivo).

---

## 🧠 Aprendizajes Clave

1. **Estructura de etiquetas multimedia:** Entendí la diferencia entre usar el atributo `src` directo en la etiqueta principal y usar la etiqueta hija `<source>` (siendo esta última la mejor práctica para entornos de producción).
2. **Control de flujo en Git:** Práctica de la estrategia de "paquete" agrupando archivos relacionados (`index.html` y `README.md`) en un único commit con sentido completo.
