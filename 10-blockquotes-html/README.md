# Ejercicio 10: Elementos de Cita en HTML (Blockquotes)

## 🎯 Objetivo
El objetivo de este ejercicio era practicar con las etiquetas de HTML semántico destinadas a representar citas de texto, diferenciando entre citas cortas en línea y bloques de cita grandes y complejos. Además, se ha trabajado en la traducción y adaptación del contenido original para mejorar la accesibilidad en español.

---

## 🧠 Conceptos Clave Aprendidos

* **`<q>` (Inline Quotation):** Utilizada para citas cortas insertadas directamente dentro de un párrafo. En este ejercicio la usamos para la frase de Quincy: *"Puedes convertirte en desarrollador."*
* **`<blockquote>` (Block Quotation):** Utilizada para citas largas que ocupan un bloque propio. Se aplicó en las tres secciones de consejos.
* **Atributo `cite`:** Se utilizó tanto en `<q>` como en `<blockquote>` para indicar la URL de la fuente original de donde se extrajo el texto (el libro de freeCodeCamp).
* **`<cite>` (Citation):** Utilizada para dar el título de la obra de referencia. En este caso, el libro de Quincy Larson.
