# Ejercicio 11: Página de Blog de Gatos (Mr. Whiskers) 🐱

En este proyecto he desarrollado la estructura completa de un blog personal utilizando **HTML5 Semántico**. El objetivo principal ha sido organizar el contenido de forma lógica y accesible, separando las diferentes secciones de una página web real.

## 🎯 Objetivos de Aprendizaje

* **Estructura Semántica Avanzada:** Uso de las etiquetas principales `<header>`, `<main>`, `<section>`, `<article>` y `<footer>`.
* **Navegación Interna (Anclas):** Implementación de un menú de navegación mediante enlaces (`<a>`) que apuntan a identificadores (`id`) específicos dentro de la misma página.
* **Contenido Independiente:** Uso de la etiqueta `<article>` para encapsular posts de blog que tienen sentido por sí mismos.
* **Información de Contacto:** Uso correcto de la etiqueta `<address>` y protocolos de enlace para teléfonos (`tel:`) y correos electrónicos (`mailto:`).
* **Multimedia con Significado:** Implementación de figuras (`<figure>`) y leyendas de imagen (`<figcaption>`).

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Enfocado en la semántica y la jerarquía de contenidos.
* **Marcado de Texto:** Uso de encabezados jerárquicos (`<h1>`, `<h2>`, `<h3>`) y párrafos descriptivos.

## 📝 Notas del Proyecto

Este ejercicio consolida la base necesaria para crear sitios web complejos. La separación clara entre el "encabezado", el "contenido principal" y el "pie de página" es fundamental antes de empezar a aplicar estilos con CSS.
