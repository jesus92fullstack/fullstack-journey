# Ejercicio 13: Formulario de Comentarios del Hotel 🏨

Este proyecto consiste en la creación de un formulario de retroalimentación (feedback) completo y accesible, diseñado para capturar la experiencia de los clientes tras su estancia en un hotel.

## 🎯 Objetivos del Proyecto

El objetivo principal fue profundizar en la estructura de formularios complejos en HTML5, asegurando una correcta captura de datos y una experiencia de usuario (UX) óptima.

## 🚀 Tecnologías y Conceptos Aplicados

* **HTML5 Semántico:** Uso de etiquetas como `<header>`, `<main>`, `<fieldset>` y `<legend>` para una estructura clara.
* **Accesibilidad (A11y):** Vinculación estricta de elementos `<label>` con sus respectivos `<input>` mediante los atributos `for` e `id`.
* **Validación Nativa:** Implementación de atributos de validación como `required`, `min`, `max` y tipos de entrada específicos (`email`, `number`).
* **Gestión de Datos:** Configuración técnica de atributos `name` y `value` para el envío de datos mediante el método `POST`.
* **Localización:** Interfaz traducida íntegramente al español para mejorar la usabilidad.

## 🛠️ Herramientas Utilizadas

* **VS Code:** Editor principal de desarrollo.
* **Prettier:** Para garantizar una sangría e indentación profesional y consistente.
* **Git:** Control de versiones para el seguimiento del progreso.
* **freeCodeCamp:** Plataforma de origen del desafío técnico.

## 📸 Captura de Estructura

El formulario se divide en cuatro secciones lógicas:
1.  **Información Personal:** Captura de datos básicos con validación de formato.
2.  **Historial de Estancia:** Uso de `radio buttons` para selección única.
3.  **Motivos de Elección:** Uso de `checkboxes` para selección múltiple.
4.  **Calificaciones y Comentarios:** Menús desplegables (`select`) y área de texto libre (`textarea`).
