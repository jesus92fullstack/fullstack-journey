# 🎵 Proyecto: Reproductor de Música HTML

Este es un proyecto práctico del curso de **freeCodeCamp** enfocado en el uso de etiquetas multimedia nativas de HTML5, concretamente para la reproducción y control de archivos de audio.

## 🎯 Objetivos del Proyecto
En este laboratorio estoy implementando:

* **Uso de `<audio>`:** Inserción de reproductores de sonido directamente en el navegador sin necesidad de plugins externos.
* **Atributos de Control:** Manipulación de opciones como `controls` (para pausar y reproducir), `autoplay` y `loop`.
* **Estructura Semántica:** Organización de la interfaz del reproductor usando etiquetas estándar de HTML5.

## 🛠️ Tecnologías utilizadas
* **HTML5:** Uso específico del elemento multimedia `<audio>` y sus etiquetas hijas `<source>`.
* **Markdown:** Para la documentación legible de este repositorio.

## 🎧 Características del Reproductor
* Soporte para múltiples formatos de audio (MP3, OGG).
* Interfaz nativa del navegador para pausar, reproducir y controlar el volumen.
