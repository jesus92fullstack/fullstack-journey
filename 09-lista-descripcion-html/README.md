# Ejercicio 9: Lista de Descripción en HTML

## 🎯 Objetivo
El objetivo de este ejercicio era comprender y aplicar las listas de descripción en HTML (`<dl>`), aprendiendo a estructurar información que viene en parejas de términos y descripciones, y entendiendo su valor para el HTML semántico y la accesibilidad.

---

## 🧠 Conceptos Clave Aprendidos

* **Etiquetas Semánticas de Lista:** * `<dl>` (*Description List*): El contenedor padre que agrupa toda la lista.
  * `<dt>` (*Description Term*): El término, título o concepto que queremos definir.
  * `<dd>` (*Description Description*): La descripción, definición o valor asociado al término.
* **Buenas Prácticas de Accesibilidad:** El uso de estas etiquetas permite que los lectores de pantalla y los motores de búsqueda entiendan la relación directa entre un concepto y su definición.
* **Flexibilidad:** Aprendí que es totalmente válido asociar múltiples etiquetas `<dd>` a un solo `<dt>`.

---

* **HTML5** (Semántico)
* **VS Code** como editor de código local.
