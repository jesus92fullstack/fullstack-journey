Lista de los principales navegadores web

   
Google Chrome
       
Se trata de un navegador web gratuito desarrollado por Google y lanzado por primera vez en 2008.
       
Firefox
           
Se trata de un navegador web gratuito desarrollado por la corporación Mozilla y lanzado por primera vez en 2004.
   
Safari
           
Se trata de un navegador web desarrollado por Apple y es el navegador predeterminado para los dispositivos iPhone, iPad y Mac.
   
Brave
           
Se trata de un navegador web gratuito lanzado por primera vez en 2016 y basado en el navegador web Chromium.
Arc
           
Se trata de un navegador web gratuito basado en Chromium lanzado por primera vez en 2023 por The Browser Company.
