# 🎬 Proyecto: Reproductor de Video HTML

Este es un proyecto práctico del curso de **freeCodeCamp** enfocado en el uso de etiquetas multimedia nativas de HTML5, concretamente para la reproducción y control de archivos de video.

## 🎯 Objetivos del Proyecto
En este laboratorio estoy implementando:

* **Uso de `<video>`:** Inserción de reproductores de video directamente en el navegador sin necesidad de plugins externos.
* **Soporte Multiformato:** Inclusión de múltiples etiquetas `<source>` (MP4, WebM, OGG, MOV) para asegurar que el video se vea en cualquier navegador.
* **Atributos Avanzados:** Uso de `poster` (imagen de portada), `muted` (silenciado), `loop` (bucle) y `controls`.

## 🛠️ Tecnologías utilizadas
* **HTML5:** Uso específico del elemento multimedia `<video>` y sus etiquetas hijas `<source>`.
* **Markdown:** Para la documentación legible de este repositorio.

## 📺 Características del Reproductor
* Ancho fijo de 640 píxeles.
* Imagen de portada personalizada antes de la reproducción.
* Reproducción automática silenciada y en bucle infinito.
