# Compilación de Vídeos: Éxito en Programación

Página de recursos donde recojo consejos clave sobre resiliencia, buenas prácticas y hábitos para desarrolladores. Este ejercicio práctico profundiza en la estructuración de documentos HTML con contenido embebido complejo.

## 🎯 Objetivos del Ejercicio
* Dominar el uso de múltiples elementos `<iframe>` en un solo documento.
* Práctica avanzada de indentación y legibilidad de código HTML5.
* Aplicación de buenas prácticas en títulos de accesibilidad (`title`).

## 🛠️ Tecnologías
* **HTML5:** Uso de etiquetas semánticas (`main`, `section`) y marcos interactivos (`iframe`).
