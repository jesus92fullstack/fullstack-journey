# Ejercicio 12: Centro de Eventos (Event Hub) 📅

En este proyecto he construido un panel de gestión de eventos utilizando **HTML5 Semántico**. El enfoque principal ha sido la organización de información cronológica y el uso de multimedia accesible.

## 🎯 Objetivos de Aprendizaje

* **Semántica de Tiempo:** Uso de la etiqueta `<time>` con el atributo `datetime` para estandarizar fechas.
* **Accesibilidad Web:** Implementación de atributos `alt` descriptivos en imágenes para mejorar la experiencia con lectores de pantalla.
* **Navegación por Anclas:** Vinculación de secciones mediante IDs (`#upcoming-events` y `#past-events`).
* **Estructura de Artículos:** Organización de eventos individuales mediante la etiqueta `<article>` dentro de secciones temáticas.

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica avanzada.
* **ISO 8601:** Formato estándar para fechas en el código.
